# 어종 인식 모델

Colab 학습 노트북(`tools/train_fish_model.ipynb`)이 Drive에 저장한 파일을 여기에 복사하세요:

- `fish_model.tflite`
- `labels.txt`

이 두 파일이 있어야 "설정 → (버전 7연타) 개발자 메뉴 → AI 어종 인식 테스트"가 동작합니다.
파일이 없으면 테스트 화면에 "모델 로드 실패" 안내가 표시됩니다.

> 모델 입력 사양: 224×224×3, RGB, float32, 픽셀값 0~255 (정규화는 모델 내부 처리).
> `labels.txt` 순서 = 학습 시 클래스 순서. 반드시 이 파일로 인덱스→어종명을 매핑합니다.
