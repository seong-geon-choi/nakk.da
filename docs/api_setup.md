# API 키 설정

낚.다는 날씨·물때 정보를 위해 공공데이터포털 API를 사용합니다.

---

## 국립해양조사원 (KHOA) API

물때(조위), 수온 정보를 제공합니다.

### 발급 방법

1. [공공데이터포털](https://www.data.go.kr) 회원가입 / 로그인
2. 검색: **"국립해양조사원 조위관측 조회 서비스"**
3. 활용신청 → 자동 승인
4. 마이페이지 → 개발계정 → 해당 API → **디코딩 키** 복사

### 앱에 입력하는 방법

**방법 1 — 소스코드 직접 수정**

`lib/core/constants/api_keys.dart` 파일에서 기본값을 교체합니다.

```dart
const String kDefaultKhoaApiKey = '여기에_발급받은_디코딩_키_입력';
```

**방법 2 — 앱 설정 화면에서 입력**

앱 실행 → 설정 → KHOA API 키 항목에서 직접 입력합니다.
설정 화면에서 입력한 키는 `shared_preferences`에 저장되며, 소스코드 기본값보다 우선합니다.

---

## 기상청 API (내장)

현재 기온 정보는 기상청 초단기실황 API를 사용합니다.
별도 키 발급 없이 `lib/features/weather/data/weather_service.dart` 내부에 설정되어 있습니다.

> 기상청 API는 요청 횟수 제한이 있을 수 있습니다. 상업적 사용 시 별도 키를 발급받아 사용하세요.

---

## API 미설정 시 동작

API 키가 없거나 잘못된 경우:
- 물때 정보: 표시되지 않음 (대시 `-` 표시)
- 수온: 표시되지 않음
- 기온: 별도로 동작 (기상청 API)

나머지 기능(음성 메모, 사진 촬영, GPS, 지도 등)은 API 키 없이도 정상 동작합니다.
