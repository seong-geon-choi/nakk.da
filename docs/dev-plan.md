# vo-rec 개발 계획

**앱 개요:** 안드로이드 기반 낚시/야외 활동 특화 음성 메모 앱  
**프레임워크:** Flutter  
**저장 방식:** 로컬 파일 (날짜별 .md, 사진은 photos/ 폴더)

---

## 메모 파일 포맷

**파일명:** `YYYY-MM-DD.md`

### 구조 규칙
- `## 현황` 블록: 파일 생성 시 1회 자동 기록. 위치 이동 시 수동으로 추가 가능 (시간 표기)
- 각 메모 엔트리: 시간 + GPS + 텍스트
- 사진 엔트리: 시간 + GPS + 이미지 링크 (텍스트 없어도 됨)

```markdown
# 2026-06-02

## 현황
- 📍 경남 통영시 미수동
- 🌡 기온: 22°C | 🌊 3물 (간조 12:45) | 💧 수온 18.5°C
- 관측소: 통영항 (4.2km)

---

### 10:23 | 🛰 34.8547, 128.4336
감성돔 노림. 조류 약하고 바람 없음.

---

### 11:45 | 🛰 34.8547, 128.4336
감성돔 30cm 한 마리.

---

### 11:52 | 🛰 34.8547, 128.4336
![](photos/2026-06-02_11-52-10.jpg)

---

## 현황 (14:30 장소)
- 📍 경남 통영시 한산도
- 🌡 기온: 24°C | 🌊 4물 (만조 16:20) | 💧 수온 19.0°C
- 관측소: 통영항 (8.1km)

---

### 14:45 | 🛰 34.7821, 128.5012
장소 이동 후 첫 메모.

---
```

### 위치 이동 UX
- 메인 화면에 **위치 추가** 버튼 표시 (설정에서 표시/숨김 선택 가능)
- 탭 시 팝업: "현재 위치 정보를 새로 기록할까요?" → 확인 시 현황 블록 추가
- 설정 항목: `위치 이동 버튼 표시 ON/OFF`

## Phase 1 — MVP Core

- [ ] 1. 앱 기본 구조 + 권한 처리 (마이크, 위치, 저장소, 카메라)
  - 검증: 권한 요청 플로우 정상 동작
- [ ] 2. 날짜별 .md 파일 생성 + 메모 추가 (포맷 위)
  - 검증: 파일에 메모 블록 정상 기록
- [ ] 3. 음성 인식 → 텍스트 변환 + 메모 저장 (speech_to_text)
  - 검증: 말하면 파일에 텍스트로 기록
- [ ] 4. 사진 촬영/첨부 + 메모에 사진 링크 기록 (image_picker)
  - 저장 경로: `photos/YYYY-MM-DD_HH-mm-ss.jpg`
  - 검증: 사진 촬영 후 메모에 링크 삽입 확인
- [ ] 5. 메모 목록/뷰어 (파일 목록, 내용 보기, 파일명 변경, 삭제)
  - 검증: CRUD 동작 확인

## Phase 2 — 환경 정보 자동 입력

- [ ] 6. GPS 수집 + 역지오코딩 (시/군/면 주소)
  - 검증: 메모에 주소 자동 삽입
- [ ] 7. 기상청 API → 기온 자동 입력
  - 검증: 메모에 기온 표시
- [ ] 8. 해양조사원 조위관측소 목록 내장 + GPS 기반 최근접 관측소 계산
  - 검증: "통영항 (4.2km)" 식으로 표시
- [ ] 9. 해양조사원 API → 물때 + 수온 자동 입력
  - 검증: 메모에 "3물 (간조 12:45) | 수온 18.5°C" 표시

## Phase 3 — 하드웨어 버튼 트리거

- [ ] 10. Android 접근성 서비스 구현
  - 볼륨↑ 2회 연속 (1초 내) → 녹음 시작/중지
  - 화면 꺼진 상태 + 포그라운드 서비스로 유지
  - 검증: 화면 오프 상태에서 볼륨 더블클릭으로 녹음 토글

## Phase 4 — 지도 보기

- [ ] 11. flutter_map + GPS 좌표로 메모 위치 핀 표시
  - 날짜 범위 필터
  - 검증: 지도에 메모 위치 핀 표시

## Phase 5 — AI 기능 (추후)

- [ ] 12. 사진으로 물고기 길이 측정
