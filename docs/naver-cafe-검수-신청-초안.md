# 네이버 카페 글쓰기 API 검수 신청서 초안 (낚.다)

> 작성일: 2026-06-17 · 상태: **초안(보류)** — 앱 정식 릴리스 후 제출 예정.
> 배경: spike 실측 결과 카페 글쓰기는 검수 승인 전 `024(Scope Status Invalid)`로 호출 불가 확정(서로 다른 토큰 3회 동일). 검수 통과 시 `content`(HTML 지원)로 글·사진 인라인 발행 가능. 상세는 [blog-publish-plan.md](blog-publish-plan.md).
>

> - [ ] 서비스 URL / 스토어 링크 / 데모 영상 준비
> - [ ] 개인정보처리방침에 "네이버 카페 발행 시 사용자 콘텐츠 전송" 명시
> - [ ] 노출됐던 Client Secret 재발급 완료

## 1. 서비스 소개

**낚.다(Nakkda)** — 낚시 조행(釣行) 기록 모바일 앱.
사용자는 낚시 중 어획 기록(어종·길이·시간), 위치·수온·물때, 사진을 메모로 남기고, 하루치 기록을 조행기로 정리합니다.

- 플랫폼: Android (패키지명 `com.sgchoisg.nakkda`)
- 서비스 URL / 스토어: *(출시 후 기입)*

## 2. 카페 API 사용 목적

**사용자가 자신이 작성한 하루치 조행 메모(어획 기록 + 사진)를, 본인이 가입·쓰기 권한을 가진 네이버 낚시 카페에 직접 발행**하기 위함입니다.

낚시 동호회는 네이버 카페에 밀집해 있어, "내 조행 기록을 내 카페에 공유"는 사용자의 자연스러운 동선입니다. 현재는 시스템 공유(사진 첨부 + 본문 텍스트)로 제공 중이나, 글과 사진이 본문 안에서 분리 배치되는 한계가 있어, `content`(HTML)로 **글·사진이 어우러진 조행기 형태**로 발행하기 위해 카페 글쓰기 API 권한을 신청합니다.

## 3. 사용 방식 (플로우)

```
[사용자] 앱에서 하루치 조행 메모 작성(어획·사진·위치)
   → "카페에 발행" 선택
   → 네이버 아이디로 로그인(OAuth) · 본인이 가입한 카페/게시판 지정
   → 앱이 메모를 HTML 본문으로 변환(어종·길이·위치 + 사진 인라인)
   → 사용자가 내용 확인 후 [발행] 버튼을 직접 누름
   → 카페 글쓰기 API 1회 호출
```

- 발행 대상: **사용자 본인이 가입·쓰기 권한을 가진 카페**에 한함.
- 발행 주체: **사용자 본인.** 최종 [발행]은 사용자가 직접 누르며, 앱이 자동·예약·반복 게시하지 않음.
- 호출 규모: 사용자당 **조행 1건 = 글 1건**(낚시를 다녀온 날에 한해 수동 발행). 대량·고빈도 호출 없음.

## 4. 스팸·오·남용이 아님을 보증하는 설계

- **자동 대량 게시 없음** — 사용자가 건건이 직접 발행. 스케줄러·봇 발행 기능 없음.
- **광고성 콘텐츠 아님** — 사용자 본인의 조행 기록(어획·사진·환경)만 발행. 마케팅·홍보 문구 삽입 없음.
- **임의 카페 배포 불가** — 사용자가 가입·쓰기 권한을 가진 카페로만. 타 카페 자동 배포 기능 없음.
- **본인 콘텐츠만** — 발행되는 글·사진은 모두 사용자가 앱에서 직접 작성·촬영한 것.

## 5. 개인정보 / 데이터 처리

- 네이버 로그인 access token은 **발행 시점에만** 사용하며, 별도 서버 수집 없이 기기에서 처리(또는 보안 저장소 보관).
- 발행되는 데이터: 사용자가 작성한 메모 텍스트와 본인 촬영 사진. 제3자 데이터 없음.
- 카페·게시판 선택, 발행 여부는 전적으로 사용자 동의·조작에 따름.

## 6. 요청 권한

- 네이버 로그인(프로필 식별)
- **카페 — 게시글 쓰기**(`POST /v1/cafe/{clubid}/menu/{menuid}/articles`)
