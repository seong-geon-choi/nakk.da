# 기능 검토 리포트 (낚.다)

**작성일:** 2026-06-12
**대상:** 낚시 다이어리 앱 vo-rec
**목적:** 추가하면 좋을 기능 / 개선할 기능 정리 및 진행 우선순위 결정

---

## 현재 구현 수준

핵심 기록 흐름은 상용 앱 수준으로 완성됨.

- 음성/텍스트/사진/동영상 메모 + GPS + 환경정보(기온·풍속·날씨·물때·수온) 자동 입력
- 날짜별 `.md` 저장 (SAF), 파일 목록/뷰어/편집/삭제
- 지도 (GPS 핀 + 경로 클러스터링), 이동경로 트래킹
- AR 길이 측정, 워터마크, 날짜별 사진 일괄 추가
- 볼륨버튼/흔들기 빠른 실행, 접근성 서비스(화면 꺼짐 지원)
- 구글 드라이브 백업/복원

---

## 1. PRD 미구현 — 어종(물고기 종류) 기록

`PRD.txt` / `dev-plan.md` Phase 5 항목 13 "물고기 종류 인식"이 미구현.
현재 `MemoEntry`에는 `fishLength`(길이)만 있고 **어종/마릿수 필드가 없음.**

**방향:** AI 인식보다 먼저 **수동 어종 태그**(드롭다운 또는 자유입력 칩)를
`MemoEntry`에 구조화 필드로 추가. AI 인식은 이후 그 위에 얹는다.
→ 어종 필드가 없으면 검색/통계를 만들 수 없으므로 **선행 작업**.

---

## 2. 추가하면 좋을 기능 (우선순위)

| 우선 | 기능 | 이유 |
|------|------|------|
| ★★★ | 메모 검색/필터 | 날짜·장소·어종·텍스트로 과거 기록 찾기. 현재 검색 진입점 없음 |
| ★★★ | 조과 통계/대시보드 | 어종별 마릿수, 최대 사이즈(PB), 월별·장소별 집계. 어종 필드 선행 필요 |
| ★★ | 물때 예보(미래 조석) 뷰 | 출조 계획용 만조·간조 시각/그래프. 해양조사원 API 확장으로 가능 |
| ★★ | 일출/일몰(골든타임) 표시 | 위경도만으로 계산 가능. `LocationStatus`에 추가 |
| ★ | 하루 기록 공유/내보내기 | 이미지 카드/텍스트로 커뮤니티 공유 |

## 3. 개선할 기존 기능

- **드래그 FAB 위치 미저장**: `_LocationFab`/`_TrackingFab` 위치가 재진입 시 초기화. settings에 저장 + 겹침 방지
- **죽은 주석**: `location_status.dart:5` "Phase 2 필드 (현재는 항상 null)" — 실제로는 값이 채워짐. 정리
- **음성 자동저장 위치 fallback UX**: 위치 못 구하면 조용히 GPS 없이 저장. "위치 없이 저장됨" 힌트 필요
- **테스트 부재**: `md_serializer`(파싱/직렬화), 백업 병합 로직은 데이터 유실 위험 핵심부. 단위 테스트 권장

## 추천 로드맵

데이터 모델(어종 필드)을 공유하는 흐름으로 묶어 진행:

1. **어종/마릿수 구조화 필드 추가** (`MemoEntry` + `.md` 포맷 하위호환)
