## 2026-06-12 — 조과 기록 · 검색 · 통계 · 워터마크 · 카메라 UX

### 조과(어종/길이) 기록
- **어종·길이 필드 추가**: 메모 엔트리에 어종(`fishSpecies`)·길이(`fishLength`) 구조화 저장. `.md` 포맷 하위호환
- **텍스트 자동 인식**: 음성/수동 메모 내용에서 어종("감성돔")·길이("38cm/38센치/38짜리")를 자동 추출해 입력
- **어종 목록 사용자 관리**: 설정에서 어종 추가/삭제, 메모 작성 시 직접 입력한 신규 어종 자동 등록, 가나다순 정렬, 중복 체크·실시간 필터링·순번 표시
- **마릿수 단순화**: "사진/메모 1건 = 1마리" 기준으로 집계 (마릿수 입력 제거)

### 검색
- 메모 목록에 **검색** 진입점 추가. 텍스트·어종·장소(주소) 검색 + 어종 칩·날짜 범위 필터
- 전체 엔트리 1회 로드 후 메모리 필터링(즉시 반응), 날짜별 그룹 결과 → 탭 시 해당 메모로 이동

### 조과 통계
- **통계 대시보드**: 기간(전체/올해/이번 달) + 요약(총 마릿수·어종 수·기록일) + 어종별 집계(최대 길이 PB) + 월별 막대

### 워터마크
- **자유 위치(플로팅)**: 4코너 고정 → 임의 위치. 설정 미리보기·일반 카메라·AR 카메라 모두 **드래그로 이동**
  (잡은 지점 기준 상대 이동으로 통일, 점프·지연 없음)
- **날짜 포맷 추가**: `연-월-일 시:분:초`, `연-월-일 시:분`. 결합 포맷 선택 시 시간 라인 자동 토글
- **아이콘 통일**: 설정·일반 카메라·AR 카메라 모두 물방울(`water_drop`) 아이콘, 카메라 토글은 우측 중앙 배치

### 카메라 UX
- **세로 고정 + 컨트롤 회전**: 가로로 돌려도 레이아웃(촬영 버튼 등)이 고정되고, 컨트롤·워터마크 박스만 90° 회전(`sensors_plus` 기반). AR 카메라도 동일(`OrientationEventListener`)
- **워터마크 위치 즉시 반영**: 카메라/AR에서 옮긴 위치가 설정에 저장되고 촬영 사진에 동일 적용

### 품질
- 단위 테스트 확충(직렬화·통계·어종/길이 탐지·설정 영속화 등) — 총 **150개 통과**
- 기존 stale 테스트 정리, `_countEntries` 카운트 버그 수정, 트래킹 토글 화면 깜빡임 수정
