# 기능 상세

## 1. 메모 보기 화면 (오늘 / 날짜별 통합)

오늘·과거 날짜를 **단일 화면(`DayMemoScreen`)** 으로 통합해 표시합니다.
앱 진입 시에는 오늘 날짜로 열리고, 목록에서 날짜를 선택하거나 스와이프로 다른 날짜를 봅니다.

- **표시 날짜는 경로로 판정**: 오늘이면 설정 버튼, 과거면 '오늘' 버튼 노출(별도 화면 아님)
- **좌우 스와이프**(빈 영역): 이전/이후 날짜 메모로 전환 — 라우트 이동이 아니라 화면 안에서 날짜만 바꿔 뒤로가기 동작이 일관됨
- **당겨서 새로고침**(Pull-to-refresh): 상단 새로고침 버튼 대신 목록을 당겨 갱신
- 하단 바: 메모 / 사진 / 지도
- 메모 카드 스와이프: 수정 / 삭제
- 현황 카드의 🌊 물때 줄 탭 → 당일 만조/간조·일출몰·월령 팝업
- 홈 전용(앱 진입 시 1회): 음성 결과 수신, 인앱 업데이트 안내, 저장폴더 자동 설정

---

## 2. 음성 메모

### 인앱 음성 입력

메모 입력 시트의 마이크 버튼으로 `speech_to_text`를 통해 실시간 음성 인식.

### 볼륨 버튼 트리거 (화면 꺼진 상태)

`VoiceRecordForegroundService` 가 백그라운드에서 동작합니다.

| 동작 | 결과 |
|------|------|
| 볼륨 감소 버튼 1회 | 음성 인식 시작 (SpeechRecognizer) |
| 볼륨 감소 버튼 연속 2회 | 인식 취소 |

인식 완료 후 결과 텍스트는 브로드캐스트 → Flutter → 홈 화면의 메모에 자동 저장됩니다.

> 앱 첫 실행 후 마이크 권한 허용 시 서비스가 자동 시작됩니다.

## 3. 사진 촬영

### 일반 카메라 (줄자 모드)

화면에 줄자 오버레이가 없는 일반 카메라입니다.

- 핀치 줌 (두 손가락 벌리기/오므리기)
- 탭 초점 조정
- 우측 중앙 워터마크 토글 버튼
- 촬영 후 물고기 길이 입력 시트 표시

### AR 카메라 (실측 모드)

ARCore를 이용한 실제 거리 측정 카메라입니다.

1. 카메라를 평평한 바닥에 향함 → 평면 감지
2. 머리 끝 터치 → 꼬리 끝 터치
3. 두 점 사이 3D 거리를 cm 단위로 표시
4. 촬영 버튼 → 측정선·수치가 합성된 사진 저장

토글 옵션:
- 워터마크 표시 ON/OFF
- 측정 결과 포함 저장 ON/OFF

### 갤러리 선택 / 일괄 추가

- **단건 추가**: 갤러리에서 1장 탭 → 편집 시트. 사진 **EXIF 촬영일**(네이티브 ExifInterface로 읽음)이 현재 화면 날짜와 다르면 "그 날짜 메모 vs 현재 메모" 선택
- **멀티 선택 추가**: 갤러리에서 사진을 **길게 눌러 선택 모드** → 여러 장 선택 → 상단 ＋ → **현재 보는 메모에 일괄 추가**(편집 시트 없이, 각 사진 EXIF 시각·GPS 반영)
- **날짜별 일괄 추가**(상단 📷): 날짜 선택 → 그 날짜 촬영 사진 일괄 추가. 다른 날짜면 "그 날짜 메모 vs 현재 메모" 선택. 오늘/과거 화면 동일 동작

## 4. 워터마크

`lib/features/settings/presentation/watermark_settings_screen.dart` 에서 설정합니다.

**템플릿 3종**(탭 전환): 각 템플릿은 독립적인 박스 구성·컨테이너 위치를 가지며, 활성 템플릿이 촬영에 사용됩니다. 신규 설치 시 배포 기본 템플릿 3종 제공(`WatermarkSettings.defaultTemplates()`), 활성=템플릿2(ON).

**박스 단위 자유 배치**: 하나의 컨테이너 안에 날짜 / 시간 / 텍스트1 / 텍스트2 박스를 각각 **드래그로 자유 배치**(설정 미리보기·일반/AR 카메라 공통). 컨테이너 전체 위치는 카메라 화면에서 이동·기억.

| 박스별 설정 항목 | 옵션 |
|-----------|------|
| 표시 | 박스별 ON / OFF |
| 내용 종류(텍스트 박스) | **텍스트 / 연도 / 주소**(GPS 시/군/구/동, 앞에 위치 핀 글리프) |
| 날짜 형식 | yyyy-MM-dd / yy/MM/dd / MM/dd / 영문월-일 / 연-월-일 시:분(:초) 등 |
| 시간 형식 | HH:mm / HH:mm:ss / 없음 |
| 폰트 | sans-serif / serif / monospace / heavy(번들) |
| 폰트 크기 | 슬라이더 (**4~160**, 4px 단위) |
| 굵기 | 보통 / 굵게 / 매우 굵게 |
| 정렬 | 좌 / 중앙 / 우 |
| **회전** | 0° / 90° / 180° / 270° (탭마다 순환) |
| 글자색 | 프리셋 + 컬러피커(히스토리) |
| 컨테이너 배경 | 프리셋 색 + 투명도 슬라이더 |

- **주소 토큰**: 촬영 시점에 역지오코딩으로 실제 주소를 채워 합성(주소 박스가 켜진 경우에만 조회, 오프라인이면 생략). 라이브뷰에서는 자리표시자로 표시.
- 워터마크는 `applyWatermark()`(`lib/core/utils/watermark.dart`)에서 실제 사진 픽셀에 `ui.Paragraph`로 합성됩니다(박스별 회전은 중심 기준 캔버스 회전).

## 5. GPS 및 위치 정보

### 자동 GPS 첨부

메모 생성 시 현재 위치를 자동으로 첨부합니다.

우선순위:
1. `locationProvider` 실시간 위치
2. `locationProvider.cached` 캐시된 위치
3. `Geolocator.getLastKnownPosition()` 최근 위치

### 현황 블록

홈 화면 상단 카드에 다음 정보가 표시됩니다:

- **📍 주소**: 역지오코딩 (geocoding 패키지)
- **🌡 기온**: 기상청 초단기실황 API
- **💧 수온**: 국립해양조사원 수온 API
- **관측소**: 가장 가까운 조위관측소 (tide_station_data.dart)
- **🌊 물때**: `lunar` 패키지로 정확한 음력일을 구해 **서해/인천식 7물때 체계**로 계산(음력 10일=1물 … 16일=7물 사리, 23일=조금, 24일=무시). 🌊 줄을 탭하면 당일 만조/간조 전체·조차·일출몰·월출몰·월령 팝업 표시

"현황 기록" 버튼으로 현황 블록을 메모 파일에 삽입할 수 있습니다.

## 6. 지도

`flutter_map` 기반 지도 화면에서 GPS가 첨부된 모든 메모를 마커로 표시합니다.

- 메모 파일 전체 스캔 → GPS 좌표 추출
- `CameraFit.bounds`로 모든 마커가 보이도록 초기 뷰 설정
- 단일 좌표일 경우 줌 레벨 15로 중앙 표시
- 마커 탭 → 해당 메모 파일 열기

## 7. 파일 목록

날짜별로 저장된 메모 파일(`.md`) 목록을 표시합니다.

- 파일명 (날짜), 첫 번째 항목 텍스트 미리보기, 항목 수 표시
- 탭 → `FileViewerScreen`에서 메모 내용 표시
- 메모 파일 내 사진 탭 → 전체 화면 뷰어 (InteractiveViewer)

## 8. 설정

| 설정 | 설명 |
|------|------|
| 메모 저장 경로 | 텍스트 메모 파일(.md) 저장 위치 |

| 워터마크 설정 | 상세 워터마크 설정 화면으로 이동 |
| 전체 파일 접근 권한 | DCIM 폴더 직접 접근 권한 요청 |

## 9. 권한 체계

| 권한 | Flutter | 필수/선택 | 용도 |
|------|---------|-----------|------|
| `RECORD_AUDIO` | `Permission.microphone` | 필수 | 음성 메모, Foreground Service |
| `ACCESS_FINE_LOCATION` | `Permission.locationWhenInUse` | 필수 | GPS 좌표 기록 |
| `CAMERA` | `Permission.camera` | 필수 | 사진 촬영 |
| `READ_MEDIA_IMAGES` | `Permission.photos` | 필수 | 갤러리 사진 선택 |
| `READ_MEDIA_VIDEO` | `Permission.videos` | 필수 | 갤러리 동영상 선택 |
| `POST_NOTIFICATIONS` | `Permission.notification` | 필수 | 서비스 알림 |

> Android 13+에서 `photo_manager`가 `PermissionState.authorized` 상태가 되려면 `READ_MEDIA_IMAGES`와 `READ_MEDIA_VIDEO` 모두 필요합니다.

## 10. 출조정보 (하루 단위)

날짜별 메모에 그날 출조의 선박·태클·조과를 구조화 기록합니다(`OutingEditSheet`).

- **선사 정보**: 선박명 · 항구 · 포인트 · 낚시 종류 · 평균 수심 · 별점 · 나의 평가(자유 텍스트) · 출항/입항 시간 · 물때 요약/보간 그래프
- **태클 세트**(최대 3): 로드 / 릴 / 라인 / 채비
- **최종 조과**: 어종 + 마릿수(여러 줄)
- 입력 값의 선택지(선박명·항구·포인트·어종, 로드·릴·라인·채비)는 **전역 프리셋**으로 누적되어 다른 날짜에서 재사용(설정에 저장 + Google Drive 백업 대상)
- 저장 위치: 날짜별 `.md`의 `## 출조정보` 가독 섹션 + `[//]: # (outing:JSON)` 숨김 주석
- 표시 조건: 메모 복잡도 = **낚시(상세)** 일 때 날짜 화면 상단 `OutingSummaryCard` 노출

## 11. 메모 복잡도 모드

설정에서 메모 입력 항목의 복잡도를 선택합니다(`MemoComplexity`).

| 모드 | 설명 |
|------|------|
| 낚시(최소) | 현장정보 + 메모(조과) |
| 낚시(상세) | 조과 + 출조정보(선박·태클·조과) — **기본값(신규 설치)** |
| 일반메모 | 어종·길이 제외(일반 메모) |
