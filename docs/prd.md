## 1. 개요

### 1.1 앱 목적

낚시·야외 활동 중 손이 자유롭지 않은 상황에서도 현재 위치, 환경 정보(기온·물때·수온)와 함께 메모를 빠르게 남길 수 있는 로컬 기반 현장 기록 도구.

### 1.2 타겟 사용자

- 선상·방파제 낚시인
- 야외 활동자 (트래킹, 캠핑 등 현장 기록이 필요한 모든 사용자)

### 1.3 핵심 가치 제안

| 문제 | 해결 |
|------|------|
| 손이 젖거나 장갑을 낀 상태에서 타이핑이 어렵다 | 음성 인식으로 메모 입력 (탭 한 번으로 시작) |
| 현장 좌표·주소를 직접 입력해야 한다 | GPS + 역지오코딩으로 자동 삽입 |
| 낚시 환경 정보(물때, 수온)를 별도로 확인해야 한다 | 공공 API로 환경 정보 자동 입력 |
| 메모와 사진이 분리 저장되어 나중에 찾기 어렵다 | 날짜별 .md 파일에 사진 링크 포함 일체 저장 |
| 사진이 갤러리에 나타나지 않는다 | MediaStore API로 저장 → 갤러리 즉시 반영 |
| GPS 지점을 지도에서 확인하기 어렵다 | 날짜별 GPS 지점 지도 시각화 + 경로 연결 |

### 1.4 저장 방식

- 기본: 로컬 파일 전용 (로그인 불필요)
- 선택: Google Drive 백업 (Google 로그인 후 수동 실행)
- 메모: `[메모 저장 경로]/YYYY-MM-DD.md` (날짜별 단일 파일)
- 사진: `[사진 저장 경로]/YYYY-MM-DD_HH-mm-ss.jpg` (기본: `DCIM/vo_rec/`)

## 2. 기능 요구사항

### Epic 1. 앱 기반 구조 및 권한 관리 ✅

#### Feature 1-1. 앱 진입 및 권한 요청 ✅

**인수 조건:**
- 앱 최초 실행 시 마이크, 위치(정밀), 카메라, 사진/동영상, 알림 권한을 순차적으로 요청한다.
  - 사진/동영상: `Permission.photos` (READ_MEDIA_IMAGES) + `Permission.videos` (READ_MEDIA_VIDEO) — Android 13+ 갤러리 전체 접근에 모두 필요
- 각 권한 요청 전 해당 권한이 왜 필요한지 설명 문구를 표시한다.
- 권한 거부 시 해당 기능(음성/GPS/카메라/갤러리)만 비활성화되고 앱은 계속 실행된다.
- 설정 화면에서 권한 상태를 확인하고 OS 설정으로 이동할 수 있다. (초기 설정과 동일한 6개 항목)
- Android 11+ 에서 음성 인식 서비스(`android.speech.RecognitionService`) 접근을 위한 `<queries>` 선언.

### Epic 2. 메모 작성 및 저장 ✅

#### Feature 2-1. 날짜별 .md 파일 생성 ✅

**인수 조건:**
- 앱 실행 또는 메모 추가 시도 시 `YYYY-MM-DD.md` 파일이 없으면 자동 생성한다.
- 파일 최상단에 `# YYYY-MM-DD` 헤더를 삽입한다.
- 저장 경로는 설정에서 사용자가 지정할 수 있다.

#### Feature 2-2. 텍스트 메모 추가 ✅

**인수 조건:**
- 메모 추가 버튼 탭 시 텍스트 입력 창이 열린다.
- 저장 시 `### HH:mm | 🛰 위도, 경도` 형식의 타임스탬프 헤더가 자동 삽입된다.
- GPS가 비활성화된 경우 좌표 없이 시각만 삽입한다.
- 저장된 메모는 해당 날짜 .md 파일 맨 아래에 `---` 구분선과 함께 추가된다.

#### Feature 2-3. 음성 메모 ✅

**인수 조건:**
- 마이크 버튼 탭 → 음성 인식 시작 (빨간색으로 전환), 3초 침묵 후 자동 종료.
- 인식 중 버튼 위에 실시간 미리보기 텍스트(회색 이탤릭)가 표시된다.
- 인식이 완료되면 최종 결과가 텍스트 필드에 append된다.
- 인식 중 다시 탭하면 즉시 종료된다.
- 음성 인식 실패 시 명확한 오류 메시지와 "다시 시도" 버튼을 표시한다.
- 인식 엔진은 `speech_to_text` 패키지의 디바이스 내장 엔진을 사용한다.

#### Feature 2-4. 사진/동영상 첨부 ✅

**인수 조건:**
- 카메라 버튼 탭 시 소스 선택 시트가 표시된다: AR 길이 측정 / 카메라 / 갤러리.
- **카메라**: 화면 스와이프 또는 하단 탭으로 사진/동영상 모드 전환 가능.
  - 동영상 모드: 해상도 선택(720p/1080p), 녹화 중 타이머 표시, 중지 후 저장.
  - 사진 모드: 기존 워터마크·줌·포커스 기능 유지.
- **갤러리**: 커스텀 갤러리 화면 (`gallery_picker_screen.dart`)
  - 전체/사진/동영상 탭 필터링, 탭별 미디어 수량 표시
  - 날짜별 그룹 헤더 (오늘/어제/YYYY년 M월 D일)
  - 무한 스크롤 (80개씩, 하단 근접 시 자동 로드)
  - 우측 드래그 스크롤바로 빠른 이동
  - 길게 누르기 → 다중 선택 모드 → 삭제 (`PhotoManager.editor.deleteWithIds`)
- 선택된 사진은 MediaStore API를 통해 `DCIM/nakkda/`에 저장되며 갤러리에 즉시 표시된다.
- 선택된 동영상은 앱 전용 외부 저장소(`Android/data/.../files/videos/`)에 저장된다.
- 메모 파일에 사진은 `![](경로)`, 동영상은 `[video](경로)` 형식으로 삽입된다.
- 메모 카드 및 입력 시트에서 동영상 썸네일을 표시하며 탭 시 전체화면 재생한다.
- GPS 좌표가 사진/동영상 메모에 자동 기록된다 (locationProvider 캐시 → lastKnownPosition 순).
- 메모 하나에 사진과 동영상을 동시에 첨부할 수 없다 (마지막 선택 항목으로 대체).

#### Feature 2-5. 메모 수정 ✅

**인수 조건:**
- 홈 화면에서 항목을 왼쪽으로 스와이프하면 수정/삭제 버튼이 노출된다.
- 수정 시트에서 텍스트, GPS 좌표(위도/경도)를 직접 편집할 수 있다.
- 사진 메모(text=null)에서도 GPS 좌표를 수정하고 저장할 수 있다.
- GPS 좌표 입력 필드는 `toStringAsFixed(4)` 형식으로 초기화된다.
- 수정 시 현재 GPS로 좌표를 갱신하는 버튼 제공.

### Epic 3. 현황 블록 (위치 이동) ✅

#### Feature 3-1. 현황 블록 추가 ✅

**인수 조건:**
- 메인 화면에 **위치 추가** 버튼이 표시된다 (설정에서 표시/숨김 전환 가능).
- 버튼 탭 시 먼저 GPS·역지오코딩·기온·물때·수온을 수집한다 (로딩 표시).
- 수집 완료 후 결과 미리보기 시트가 표시된다.
- 사용자가 내용을 확인 후 **저장** 또는 **취소**를 선택한다.
- 저장 시 아래 형식의 현황 블록이 .md 파일에 추가된다.

```
## 현황 (HH:mm 이동)
- 📍 시/군/면 주소
- 🌡 기온: 22.5°C | 🌊 5물 (만조 18:03) | 💧 수온 19.6°C
- 관측소: 통영 (12.3km)
```

#### Feature 3-2. 환경 정보 자동 입력 ✅

**인수 조건:**
- GPS 기반으로 역지오코딩 주소를 자동 조회한다 (`geocoding` 패키지).
- 기상청 API로 현재 기온을 조회한다.
- 해양조사원 API로 물때(물이름·다음 조시), 수온, 최근접 관측소를 조회한다.
- API 키는 설정에서 사용자 키로 교체 가능 (기본 키 내장).
- 위 항목은 병렬로 조회한다.

### Epic 6. 지도 ✅

#### Feature 6-1. GPS 지점 지도 표시 ✅

**인수 조건:**
- 지도 메뉴 진입 시 오늘 날짜의 GPS 지점을 지도에 표시한다.
- 진입 시 모든 지점이 화면에 들어오도록 카메라 자동 조정.
- 날짜 선택으로 다른 날짜의 지점을 불러올 수 있다.
- 날짜 변경 시에도 모든 지점이 화면에 들어오도록 자동 조정.

#### Feature 6-2. 경로 연결 ✅

**인수 조건:**
- AppBar의 경로 버튼(지점 2개 이상일 때 표시)으로 모든 지점을 시간순 선으로 연결.
- 다시 탭하면 선 제거. 버튼 색상으로 on/off 상태 표시.
- 개별 마커 팝업에서도 연결/해제 가능.

#### Feature 6-3. 마커 클러스터링 ✅

**인수 조건:**
- 줌 아웃 시 근접한 지점을 주황색 원으로 묶어 개수를 표시한다.
- 줌 레벨 0.5 변화마다 클러스터를 재계산한다.
- 클러스터 탭 시 해당 지점들로 확대한다.
- 줌인으로 일정 거리 이상 벌어지면 개별 마커로 자동 분리.

#### Feature 6-4. 마커 상세 팝업 ✅

**인수 조건:**
- 개별 마커 탭 시 시각, 주소, 사진, 메모 텍스트, 물고기 길이를 보여주는 팝업 표시.
- 팝업은 시스템 네비게이션 바와 겹치지 않는 위치에 표시.

### Epic 7. Google Drive 백업 ✅

#### Feature 7-1. Google 계정 연동 및 백업 ✅

**인수 조건:**
- 설정 화면에서 Google 계정으로 로그인 후 백업을 실행할 수 있다.
- 백업 실행 시 savePath 내 모든 .md 파일과 참조된 미디어 파일을 Drive appDataFolder에 업로드한다.
- 이전 백업 이후 변경된 파일만 업로드한다 (로컬 manifest 기반 스킵).
  - manifest: `{filename: utf8_byte_length}` — 업로드 성공 시에만 갱신
- 업로드는 4개씩 병렬로 처리한다.
- 진행 상황을 진행률 바로 실시간 표시한다.
- 완료 시 스낵바로 결과(성공/실패 파일 수)를 알린다.

#### Feature 7-2. Drive 복원 ✅

**인수 조건:**
- 설정 화면에서 Drive에서 복원을 실행할 수 있다.
- Drive의 모든 파일을 로컬로 다운로드한다.
- 로컬에 같은 날짜 .md 파일이 있는 경우 블록 단위로 병합한다:
  - 타임스탬프가 같은 블록은 중복 제거 (로컬 우선)
  - 트래킹 포인트(`## 이동 경로`)도 타임스탬프 기준 병합
- 병합 후 내용이 로컬과 동일하면 파일 쓰기를 생략한다.
- 미디어 파일은 MediaStore API를 통해 복원한다 (`writePhotoBytes` 채널).
- 복원은 4개씩 병렬로 처리한다.
- 진행 상황을 진행률 바로 실시간 표시한다.
- 완료 시 스낵바로 결과를 알린다.

## 3. 비기능 요구사항

### 3.1 성능

| 항목 | 목표 |
|------|------|
| 메모 저장 응답 시간 | 탭 후 1초 이내 파일 기록 완료 |
| GPS 좌표 획득 | 메모 추가 시 최대 5초 이내 (타임아웃 시 마지막 캐시 좌표 사용) |
| 음성 인식 지연 | 발화 종료 후 3초 이내 텍스트 표시 |
| 앱 시작 시간 | Cold start 3초 이내 |
| 파일 목록 로딩 | 100개 파일 기준 1초 이내 |

### 3.2 저장소 및 데이터

- 모든 데이터는 디바이스 로컬에만 저장한다. 네트워크로 사용자 데이터를 전송하지 않는다.
- 외부 네트워크 요청: 역지오코딩, 기상청 API, 해양조사원 API, 지도 타일.
- 저장 경로 변경 시 기존 파일을 임의로 이동·삭제하지 않는다.
- 앱 삭제 시 외부 저장소의 .md 및 사진 파일은 보존된다.

### 3.3 접근성

- 주요 버튼(메모 추가, 음성 입력, 사진 첨부)의 최소 탭 영역은 48×48 dp 이상.
- 장갑 착용 상태를 고려하여 메인 액션 버튼은 화면 하단에 배치하고 충분한 간격을 둔다.
- 어두운 환경(야간 낚시)을 고려한 다크 테마를 기본 제공한다.

### 3.4 호환성

- Android 최소 버전: API 26 (Android 8.0)
- 타겟 버전: 최신 안정 Android SDK
- 태블릿 지원 불필요 (스마트폰 세로 모드 최적화)

### 3.5 오프라인 동작

- 핵심 기능(메모 작성, 사진 촬영, GPS 기록)은 인터넷 연결 없이 동작한다.
- 환경 정보(역지오코딩, 기상, 물때)와 지도 타일은 인터넷 필요.
